# BitEdit
A standalone, mobile-friendly pixel art editor.

## Why make another paint tool?
I originally made a sprite editing dev tool for my colony sim game Arcanum. That tool was pretty bare bones but it allowed me to do things like overlay images and extract sprites from spritesheets.

BitEdit is an extension of that tool adapted for a more general audience. In particular I wanted to focus on making this mobile-friendly so I could make sprites on the go!
