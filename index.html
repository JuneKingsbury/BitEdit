Help

Drawing Tools

Draw (1)
Place pixels with the current color. Hold and drag to paint continuously.
Erase (2)
Remove pixels, making them transparent. Right-click also erases.
Fill (3)
Flood-fill a contiguous area of the same color with the current color.
Dither
Fill an area with a checkerboard dither pattern using the primary and secondary colors.
Erase Fill
Click a contiguous region of the same color to erase it all to transparency.
Magic Wand (W)
Select a contiguous region of identical color. Then use Delete to erase it or Fill to recolor it.
Pick (4)
Sample a color from the canvas and set it as the current color. Long-press on touch also picks.
Replace Color
Click any pixel to replace ALL matching pixels on the canvas with your current color.
Lighten (8)
Increase the lightness of pixels you paint over. Adjust power in settings.
Darken (9)
Decrease the lightness of pixels you paint over. Adjust power in settings.

Shape Tools

Line (6)
Click and drag to draw a straight line between two points.
Circle (7)
Click and drag to draw a circle outline from center to edge.
Rectangle (R)
Click and drag to draw a rectangle outline. Hold Shift for a filled rectangle.
Ellipse (E)
Click and drag to draw an ellipse outline. Hold Shift for a filled ellipse.
Gradient
Click and drag to create a linear gradient between the primary and secondary colors.

Selection

Select (5)
Draw a rectangle to select a region. Drag to move it. Fill or Delete with toolbar buttons.
Selection Modes
After lifting a selection, use M/R/S buttons: Move (drag to reposition), Rotate (drag to rotate freely), Stretch (drag to scale/resize).
All of Color
Select every pixel on the canvas matching the primary color (global, not contiguous).
Invert
Flip the selection: selected pixels become unselected and vice versa.
Grow / Shrink
Expand or contract the selection boundary by 1 pixel.
Copy / Paste
Ctrl+C copies selection (or entire canvas) to clipboard. Ctrl+V pastes from clipboard or system clipboard.

Navigation

Pan
Two-finger drag on touch, or enable Pan Mode button for one-finger panning.
Zoom
Pinch to zoom on touch. Scroll wheel on desktop. Use the zoom slider on the left edge.

Layers

Add / Duplicate
Create a new blank layer or copy the active one.
Merge Down
Combine the active layer into the one below it.
Reorder
Use the arrow buttons or drag layers in the list.
Opacity
Control how transparent a layer appears in the composite.
Blend Modes
Set per-layer blending: Normal, Multiply, Screen, Overlay, Add, Subtract.

Settings

Mirror / Symmetry
Dropdown to select symmetry mode: Horizontal, Vertical, H+V (both), or rotational (3/4/6-fold). Keyboard M also cycles through modes.
Lock Alpha
Prevents drawing on fully transparent pixels, so you only paint within existing shapes.
Stabilize
Pixel-perfect mode: removes diagonal double-pixels from 1px freehand strokes for cleaner lines.
Grid
Toggles a per-pixel grid overlay. Click the color swatch to change grid color.
Grid Spacing
Set a custom tile-alignment grid (e.g. 8px on a 32px canvas). Shows as cyan overlay lines.
9-Slice
Show 9-slice guide overlay (yellow dashed lines at thirds) for UI sprite slicing.
Touch Offset
Distance (in pixels) the cursor draws above your finger on touch devices. Set to 0 to draw directly under your finger, or increase for better visibility.
Left Mode
Mirrors all UI controls to the left side of the screen for right-hand drawing comfort.

Palette

Presets
Load a preset palette: PICO-8, Game Boy, NES, Endesga 32, Sweetie 16, Resurrect 64.
Palette Lock
When active, any color you pick snaps to the nearest color in your palette.
Ramp
Generate a gradient ramp from your primary to secondary color, filling the entire palette.
Indexed Mode (Idx)
When active, changing a palette slot (right-click/long-press) recolors all matching pixels on the canvas. Classic indexed-color workflow for palette swaps.
Save / Load
Export palette as a .hex file or import one (.hex, .pal, .gpl).
Extract Palette
Pulls the most-used colors from the current sprite into your palette.

Sprites

Tags
Add tags to organize sprites (e.g. "player", "enemy", "tiles"). Filter the gallery by tag.
Per-Sprite Undo
Each sprite maintains its own undo/redo history when you switch between them.
Rename
Long-press a sprite thumbnail to rename it.
